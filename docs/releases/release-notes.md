# 发布记录

### 2026-09-11

- 新增智联招聘平台，支持在应用内扫码登录、搜索职位、选择城市与筛选条件、预览和自动投递在线简历。
- “BOSS 浏览器”改名为“求职浏览器”；工作台与浏览器均可选择平台，分别保存登录状态与筛选条件，切换时保存当前偏好。
- 智联使用账户中保存的在线简历，网站随投递发送平台招呼；不要求配置 AI 或导入本地简历，后续聊天可在智联网页处理。
- 逐岗核对职位 ID、岗位和公司，确认网站成功回执后记录实际招呼并继续；已投递、已沟通及结果待核对的职位自动跳过。
- 投递记录显示所属平台、支持按平台筛选；智联待核对记录可通过求职反馈只读核验，不重新发送简历。
- 保留原有 BOSS 登录、历史、AI 岗位招呼和消息回复；两平台共享本机每日尝试上限，运行期间不能切换平台。
- 智联需选择具体城市；遇到验证、网站限制、列表未刷新或目标不一致时停止，保留现场供处理。

### 2026-09-10

- 工作台支持“省份 / 地区 → 工作城市”两级选择，覆盖全国 34 个省级地区、373 个网站城市选项，保留“全国”范围。
- 已保存的城市自动匹配省份，保存和重启后恢复；切换城市时清除原城市的工作区域条件，保留其他筛选设置。
- 新增个人简历页：支持上传 PDF、DOCX、TXT 和粘贴正文；可在分析前校对提取的文字。
- 使用 DeepSeek 提取个人概况、核心技能、代表经历与成果、岗位优势，分析结果支持逐项编辑保存。
- 新增 AI 岗位招呼：逐个读取岗位详情，结合个人简历与已核对特点生成招呼，支持设置语气和表达要求。
- AI 岗位招呼改为自动流程：发现符合条件的新岗位时自动结合 JD 与当前简历生成，投递时自动使用，无需逐岗选择或点击生成；预览只生成并留痕，不发送。
- 新增招呼记录页，保存完整正文、当时的 JD、简历特点与版本、表达要求、使用模型和处理结果，重启后仍可查看。
- 同一岗位的 JD、简历与生成配置未变时自动沿用已有招呼；变化后重新生成，优先用真实项目和成果突出匹配点。
- 简历正文和分析结果保存在本机，不随配置导出；修改正文后需重新分析，支持移除本地简历且保留原文件。
- 生成失败或模型返回截断内容时停止，不发起沟通；完整招呼保存在投递记录，继续核对目标和送达回执。

### 2026-09-09

- 界面改用功能名称，移除宣传标语、重复说明和页脚；精简空状态与操作提示，保留发送确认、状态、错误及数据传输说明。
- 消息回复页新增自动回复开关：开启后定期检查网站已有会话，找到招聘方发来但本人尚未回复的消息，自动生成并核对送达；包含已读但未回复的消息。
- 新增只读扫描和回复日志，记录发现、跳过、生成、发送、失败与开关操作，保存完整回复正文；网页已有草稿和不确定的发送结果留给本人处理。
- 扫描会等待消息入口、会话列表和联系人资料加载完整，首次打开应用也可直接检查待回复消息。
- 自动回复与投递、手动回复依次运行；关闭开关取消正在生成的请求，退出或重启应用后保持关闭。
- 移除回复的 Token 参数和 1,000 字上限，按内容需要生成完整正文；模型报告截断时停止发送，不把不完整内容当作成功回复。
- 新增 DeepSeek 模型配置，支持密钥加密保存、测试连接、刷新模型和自定义系统提示词，按个人背景与表达习惯生成回复。
- 新增消息回复页：选择已沟通职位、读取近期对话、编辑草稿并确认发送；对方发来新消息时拦截过期回复，发送结果不明确时保留待核对记录。
- 修复同一公司有不同招聘者时只建立沟通、未发送文字的问题；结合招聘者姓名定位并继续核对具体职位。
- 浏览器铺满应用窗口，网页宽度随窗口自动适配，保留进度、暂停/停止、日志和返回入口。
- 修复“消息”入口带未读数字时停在简易聊天弹窗的问题；继续进入完整会话并核对送达，聊天内的竞争力卡片不影响发送。
- 修复网页浮层遮住发送按钮中心时消息停留在草稿的问题；完全遮挡时仍停止操作。
- 聊天核对不再反复切回职位页；切换联系人或职位后停止发送，等待回执时可正常接收新消息。
- 修复 macOS 切到日志后新页面偶发漏掉首个点击的问题。
- 浏览器嵌入主窗口，扫码、职位和聊天页面统一显示；开始任务后自动切换。
- 自定义每轮 1–200 次投递，显示目标进度、每日余额和提前结束原因。
- 提供三档操作节奏，减少重复加载和等待；修复 Windows 切到日志后投递中断。
- 调大投递次数时同步提高浏览范围，历史重复和不匹配职位不占本次投递次数。
- 保留原有登录和历史，旧任务不套用新的投递目标；完成一批后清理辅助页面。

### 2026-09-08

- 提供 macOS Apple Silicon 和 Windows x64 桌面安装包，自带运行环境。
- 支持职位筛选与预览、自定义招呼、暂停/继续/停止、历史查询和 CSV 导出。
- 发送前核对目标职位；同一职位共享历史去重，不确定结果禁止自动重发。
- 新增“只读核对送达”，重新检查原消息与回执，不发送新消息。
- 修复 Windows 打包服务读取和显示中文时的编码错误。

当前为未签名测试版。macOS 安装版已完成启动、登录恢复和实站预览；Electron 路径已自动发送真实消息，修正回执识别后通过只读核验确认送达。Windows 的本机安装与登录仍需实机验收。原 Playwright CLI 路径存在网站 `code=37` / 空白页兼容问题。
