# 发布记录

### 2026-09-09

- 浏览器嵌入主窗口，扫码、职位和聊天页面统一显示；开始任务后自动切换。
- 自定义每轮 1–200 次投递，显示目标进度、每日余额和提前结束原因。
- 提供三档操作节奏，减少重复加载和等待，修复切到日志后偶发的点击失效。
- 调大投递次数时同步提高浏览范围，历史重复和不匹配职位不占本次投递次数。
- 保留原有登录和历史，旧任务不套用新的投递目标；完成一批后清理辅助页面。

### 2026-09-08

- 提供 macOS Apple Silicon 和 Windows x64 桌面安装包，自带运行环境。
- 支持职位筛选与预览、自定义招呼、暂停/继续/停止、历史查询和 CSV 导出。
- 发送前核对目标职位；同一职位共享历史去重，不确定结果禁止自动重发。
- 新增“只读核对送达”，重新检查原消息与回执，不发送新消息。
- 修复 Windows 打包服务读取和显示中文时的编码错误。

当前为未签名测试版。macOS 安装版已完成启动、登录恢复和实站预览；Electron 路径已自动发送真实消息，修正回执识别后通过只读核验确认送达。Windows 的本机安装与登录仍需实机验收。原 Playwright CLI 路径存在网站 `code=37` / 空白页兼容问题。
