# 省市目录

工作台的省市选项来自 [BOSS 直聘公开城市目录](https://www.zhipin.com/wapi/zpCommon/data/city.json)，于 2026-09-10 核对并提取其中的省份及城市名称：34 个省级地区、373 个城市选项。直辖市、香港、澳门和台湾按网站目录提供的同名选项展示；这里列的是网站招聘范围，不是行政区划层级表。

目录随界面打包，选择省市无需联网。更新目录时保留网站的完整名称，例如自治州、地区和部分以“市”结尾的名称，不能统一删改后缀。省份只用于组织城市选项，配置继续保存 `search.city`，兼容已有配置及 CLI；执行搜索仍通过网站可见城市弹窗选择并核对结果。

界面验证覆盖全部省市联动、直辖市与港澳台、全国范围、旧城市配置恢复、跨城市清除工作区域和保存后的恢复。隔离浏览器验证覆盖五组字母城市菜单，并确认“福建 → 厦门”选择会用于实际搜索，预览不会发送消息。这些测试使用合成网页，不代表逐城进行真实投递。
